# FilePro Premium - Modular Codebase

## Overview
This is the refactored version of FilePro Premium, organized into a modular structure for better maintainability and scalability.

## Directory Structure
- **`main.py`**: The entry point of the application.
- **`src/`**: Source code directory.
  - **`core/`**: Core configuration and state management.
  - **`ui/`**: User Interface components.
    - **`main_layout.py`**: Main application layout and theme logic.
    - **`tabs/`**: Individual tab components.
  - **`utils/`**: Utility functions (File mapping, formatting, etc.).

## How to Run
Run the application using the new entry point:
```bash
python main.py
```

## Legacy Code
The original `FilePro_Modern.py` is preserved as a reference but should be considered deprecated.
